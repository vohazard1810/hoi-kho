# Production SFX Drop Folder

Place exported `.ogg` files here. `AudioManager` automatically preloads matching
files and otherwise uses the Web Audio synth fallback.

Required filenames:

`swing_j1.ogg`, `swing_j2.ogg`, `swing_j3.ogg`, `ultimate_charge.ogg`,
`hit_light.ogg`, `hit_medium.ogg`, `hit_heavy.ogg`, `ultimate_hit.ogg`,
`throw_tape.ogg`, `tape_hit.ogg`, `dodge.ogg`, `player_hurt.ogg`,
`enemy_warning.ogg`, `boss_warning.ogg`, `enemy_ko.ogg`, `pickup.ogg`,
`gate_open.ogg`, `order_complete.ogg`.
